# OneRep language

| Term | Meaning |
| --- | --- |
| Routine | An editable ordered list of exercises and target sets used to begin a workout. The upstream code calls this a workout template. |
| Workout | One actual training session, with a start time, optional end time, exercises, and performed sets. |
| Selected exercise | The exercise currently shown on the Watch within the active workout. Selection is manual in V1. |
| Set attempt | A period of motion collection for the selected exercise, begun by movement or the Start Set control and ended by five seconds without a detected rep or the End Set control. |
| Detected reps | The count produced by a motion detector before the lifter reviews it. |
| Final reps | The count accepted by the lifter in the set review. This is the count used in workout history and progress. |
| Rest interval | The time between saving a performed set and ending or skipping its rest countdown. |
| Workout snapshot | A versioned copy of the Watch's active workout state sent to the iPhone for display. |
